# Digital Teacher Planner

Maria Cartiera's lesson planner for St. Paul's School (Spanish, Grades 1-8).

The whole app is the single file `index.html`. It is published with GitHub Pages
and opened on Maria's tablet like an app (Chrome > Add to Home screen).

## Updating
1. Upload the new `index.html` here (Add file > Upload files > Commit changes).
2. Reopen the planner on the tablet. Plans are kept; only the app updates.

The running version is shown under the planner title (for example `v2026.08.17`).
