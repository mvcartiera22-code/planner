# Digital Teacher Planner

Maria Cartiera's lesson planner for St. Paul's School (Spanish, Grades 1-8).

Two single-file apps, published with GitHub Pages and opened on Maria's tablet
like apps (Chrome > Add to Home screen):

- `index.html` — the lesson planner
  https://mvcartiera22-code.github.io/planner/
- `participation.html` — the Grades 5-8 Spanish participation tracker
  https://mvcartiera22-code.github.io/planner/participation.html

## Updating
1. Upload the new `index.html` or `participation.html` here
   (Add file > Upload files > Commit changes).
2. Reopen the app on the tablet. Saved work is kept; only the app updates.

The running version is shown under the planner title (for example `v2026.08.17`).
